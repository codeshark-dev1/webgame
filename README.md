Little web game I made to practice my JavaScript / html / css skills. Feel free to play or use for anything you like.
Use arrow keys to move, collect coins and avoid the enemy!
Not playable on mobile :(

I used two css tutorials, one for the button and one for the particles / trails. Links to the original videos can be found next to the related code.

No AI was used in the creation of the game except for fixing the input handling.
